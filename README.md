## Project Overview
This Laravel project is a simple personal task manager that allows users to create, view, edit, remove, and update tasks. It uses a SQLite database and follows the Laravel MVC flow: routes, controllers, models, migrations, and Blade views.

## Technologies Used
- Laravel
- PHP
- SQLite
- Blade Templates

## Setup Instructions
1. Clone the repository.
2. Open the project folder.
3. Install Composer dependencies:
   ```bash
   composer install
   ```
4. Create the database and run migrations:
   ```bash
   php artisan migrate
   ```
5. Start the Laravel development server:
   ```bash
   php artisan serve
   ```
6. Open the app in your browser at http://localhost:8000.

## Notes
This project includes task creation, status toggling, due dates, and task listing in a simple dashboard-style interface.
